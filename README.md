# Ферма

Небольшая игра для телефона: героиня исследует ферму, выполняет задания и мини-игры, открывает новые локации и знакомится с их жителями.

## Как играть

Открой ссылку на игру в браузере телефона и добавь её на главный экран:

- **iPhone** (Safari): «Поделиться» → «На экран „Домой“»
- **Android** (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран»

После этого игра открывается с иконки на весь экран и работает без интернета. Прогресс сохраняется на устройстве.

Игра вертикальная. Управление: джойстик в правой нижней части экрана, кнопка действия слева внизу. На компьютере можно играть стрелками или WASD, действие — пробел.

## Устройство проекта

- `index.html` — вся игра (движок [Phaser 3](https://phaser.io))
- `lib/phaser.min.js` — движок, лежит в проекте, чтобы игра работала офлайн
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на телефон и офлайн-режим
